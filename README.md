<h1>Android App (frontend) for Optimized Supply Chain Management using Machine Learning.</h1>
<h3>
  Used: Kotlin, ViewBinding, Android Jetpack, Retrofit, Glide, Token Authentication, ViewModel</br>
  Home - For dashboard of Warehouse, Sections and Racks</br>
  Predict - For predicting the Warehouse Space and Product Order Quantity</br>
  Profile - For User profile and creating warehouse structure</br>
</h3>
